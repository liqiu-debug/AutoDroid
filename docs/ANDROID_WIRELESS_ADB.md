# Android 无线 adb 连接指南（手动方案）

## 1. 适用场景与建议

- 适合：手动调试、录制编排、单设备功能验证等交互场景。
- 不建议：批量执行、兼容性矩阵、Fastbot 长跑仍推荐 USB —— WiFi 下 adb 断连不会自动恢复，
  scrcpy 投屏码率高，长任务稳定性明显不如有线。
- 平台侧无需任何配置：Android 全链路（同步、执行、投屏、截图、Fastbot）都走 adb 寻址，
  无线连接建立后设备会作为 `IP:5555` 形态的 serial 被「一键同步物理设备」自动发现，全功能可用。

## 2. 启用步骤

1. 手机与电脑接入同一局域网（路由器未开 AP/客户端隔离）。
2. 插线，确认 `adb devices` 能看到设备。
3. 切换 tcpip 模式：

   ```bash
   adb tcpip 5555
   ```

4. 获取手机 IP：设置 → WLAN → 当前网络详情，或：

   ```bash
   adb shell ip route
   # 输出末尾的 src 地址即手机 IP
   ```

5. 拔线，建立无线连接：

   ```bash
   adb connect <手机IP>:5555
   ```

6. 平台点「一键同步物理设备」，出现 serial 为 `<手机IP>:5555` 的设备即可正常使用。

## 3. 注意事项

- **设备身份**：无线设备的 serial 是 `IP:5555`，与原 USB serial 属于两条设备记录，
  自定义名称、执行历史、报告归属互不共享。可对无线记录单独重命名以便区分。
- **重启失效**：手机重启后 tcpip 模式自动关闭，需插线重新执行步骤 3。
- **断连恢复**：WiFi 波动导致连接丢失时，设备会在同步后标记为 `OFFLINE`；
  重新执行 `adb connect` 再同步即可恢复，平台不会自动重连。
- **IP 变化**：DHCP 续租/换网会更换 IP，旧记录随之失效，建议在路由器为设备绑定固定 IP。
- **安全**：`tcpip 5555` 会在局域网开放 adb 端口（仍受 RSA 配对授权保护，但该端口是被
  广泛扫描的目标），仅在可信网络使用；用完可执行 `adb usb` 或重启手机关闭。
- Android 11+ 也可使用系统「无线调试」配对（`adb pair <IP>:<配对端口> <配对码>`），
  更安全（TLS、随机端口），但每次端口会变、需输入配对码，适合临时手动使用，
  不适合固定工位的常态化接入。

## 4. 与 iOS 无线模式的关系

- iOS 提供平台内一键无线（读取手机 IP、写入 WDA 直连配置），见 `docs/IOS_WDA_OPS.md` §3.5。
- Android 因 adb 原生支持无线，暂以本手动方案提供；若使用频率高，可评估做成
  与 iOS 对齐的「启用无线」按钮（需解决 USB/无线双 serial 的设备身份合并）。
