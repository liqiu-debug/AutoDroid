# App 跨端排查记录（2026-10-20）

本轮检查 Android App、iOS App、AutoDroid-WDA，以及共用的脚本下发、设备在线、执行报告接口。重点覆盖五个导航入口、列表与搜索、登录切换、定时调度、脚本交接、结果与通知。Web 前端完成生产构建检查。以下结论来自代码审查、隔离测试和编译，不代表已完成全部真机操作验收。

## 已修复

| 范围 | 原问题及触发条件 | 当前处理 |
| --- | --- | --- |
| iOS 五个主导航页 | 大标题与默认列表边距叠加，顶部内容偏低 | 统一使用行内标题，列表顶部内容边距为 8 pt |
| iOS 页面请求 | 全局操作忙碌时，列表、报告和目标选择的读取可能直接被丢弃 | 读取独立于修改操作的互斥；页面各自管理加载状态 |
| 双端列表 | 连续搜索、切目录或刷新，旧响应可能覆盖新条件；输入未提交时加载下一页可能混入新关键词 | 每轮加载隔离旧响应；后续页沿用已加载结果的查询条件 |
| Android 列表 | 用例/场景仅展示前 200 条，报告仅展示前 50 条，后续数据无入口 | 增加加载更多；状态展示总数与已加载数；目标选择加载完整分页后提供搜索 |
| iOS 登录恢复 | 启动时可能选中其他账号尚未结束的运行 | 恢复当前平台与账号的运行；退出后清空活动运行和通知跳转状态 |
| 双端地址与认证 | Android 非法地址可能导致请求初始化失败；旧服务请求或迟到的 401 可能影响当前会话；iOS 下载报告丢失 401 状态 | Android 统一验证和规范化地址，保留反向代理前缀；认证失败只处理对应会话；iOS 报告下载保留 HTTP 状态并接入登录失效处理 |
| 双端登录失效 | 定时器可能继续持有过期账号凭证；Android 失效后仍停留在受保护页面 | 清除定时任务或撤销闹钟；Android 返回登录页；iOS 等待旧调度清理后再允许登录 |
| Android 定时归属 | 本地任务没有平台/账号字段，切换账号可能使用另一账号执行旧目标 | Room v2 增加平台与账号；列表、保存、启用、接收器及服务均检查归属 |
| Android 旧数据升级 | 旧任务无法判断属于哪个账号 | 保留配置、停用旧任务；编辑保存后绑定当前账号，再手动启用 |
| Android 单次任务 | 过期时间在重启恢复时被安排为立即执行 | 过期单次任务不补跑，不允许直接重新启用 |
| Android 任务编辑 | 重复点击保存可能创建多条任务；编辑可能意外重新启用任务；停用任务展示 1970 年下次执行时间 | 保存期间禁用按钮，保留原开关状态，检查账号和任务是否存在，停用时显示未启用 |
| Android 重复执行 | 手动运行、定时任务和脚本准备阶段缺少统一互斥；旋转重建页面可能再次执行 | 增加统一执行预约，接收器将预约交给服务；恢复页面时跟踪原运行，不自动重跑 |
| Android 执行生命周期 | 服务提交脚本后立即结束；报告文件写入后，上报仍在进行，页面提前显示结果 | 服务等待引擎实际完成；页面在执行预约释放后读取报告；引擎异常明确显示本地错误 |
| Android 脚本包 | 未验证平台、预检与相对路径，嵌套资源目录可能写入失败 | 校验 Android 格式和预检，拒绝非法路径，创建嵌套资源目录，固定本次运行的服务器与凭证 |
| WDA 调度 | 旧任务请求迟到的 401 可能停用刚替换的新账号任务 | 仅当前调度版本的 401 可修改调度状态；状态快照加锁 |
| WDA 异常结果 | 自定义 JS 异常处理仅记录日志，异常可能被后续读取清除；主脚本无结果时缺少失败报告 | 保留并及时读取异常；无结果明确失败；为未产生报告的异常写入标准失败报告，供 iOS 补传 |
| 后端报告重传 | 同一运行重传会重建执行编号并再次发送通知；并发重试还可能同时创建记录 | 已完成结果返回原记录；SQLite 在查询前取得写入预约，持久化原子提交；通知发生在持久化之后 |
| 后端场景结果 | 同一用例在场景中出现多次时，可能重复使用最后一次结果或拿其他用例填补 | 按出现顺序分别消费，保留别名；缺失出现次数生成失败占位 |
| 配置与文档 | Android 重复声明电池优化权限；主项目文档仍写 iOS 客户端处于规划中 | 移除重复声明，更新双端说明与报告幂等契约 |

## 仍存在的能力缺口

- Android 断网或登录过期导致报告回传失败时，当前只保留本地 `report.json`，还没有与 iOS 相同的持久补传队列或重试入口。引擎在生成报告前直接异常时，当前显示本地错误，平台报告中心不会自动新增该条失败记录。
- Android 场景列表目前提供搜索，尚未接入后端已有的场景文件夹筛选；本轮已修复分页截断，目录筛选属于后续双端功能补齐。

## 真机验收边界

- 本轮没有安装到真实手机、操作真实账号/设备配置，也没有发送真实飞书通知；通知在测试中被替换。
- 尚未验证 Android 真机锁屏、省电、后台精确闹钟、前台服务限制及设备重启；这些行为依赖系统版本、权限和厂商策略。
- 尚未验证 iOS 真机切应用执行、WDA 长时间存活、通知授权与跨账号重登的完整操作链。
- 五页顶部调整已通过编译；桌面锁屏阻止了模拟器界面操作，因此没有作出调整后实机视觉验收的结论。
- Android Room v1 到 v2 的迁移 SQL 已完成代码审查并通过 Room 编译校验，尚未在真实旧版本数据上执行升级验收。升级后旧任务需要重新保存绑定，再启用。
